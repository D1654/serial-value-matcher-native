# 架构说明

状态：当前 native 架构总览。详细边界请阅读 [Win32原生架构.md](Win32原生架构.md)。

## Win32 native 发布路线

```text
svm-native-win32
  ├─ NativeMainWindow                 Win32 UI、菜单、布局、消息循环
  ├─ Win32SerialSession               唯一串口设备 HANDLE 和会话 owner
  │   ├─ SerialSession                生命周期和控制线窄接口
  │   ├─ SerialByteStream             deadline + typed result 字节接口
  │   └─ SerialWriteScheduler         双预算写队列和 exactly-once 终态
  ├─ native_storage                   Qt-free 本地存储
  ├─ svm_slim_core
  │   ├─ SerialRtuTransport           字节接口到 Modbus RTU exchange 的 adapter
  │   ├─ protocol_core                字节解析、显示格式
  │   ├─ modbus_core                  Modbus RTU 请求、响应、扫描计划
  │   ├─ analysis_core                候选生成和规则验证核心
  │   └─ report_core                  Markdown 报告文本
  └─ utf8_win32                       UTF-8 / UTF-16 转换
```

特点：

- 不链接 Qt；
- MSVC Release 使用静态运行库策略；
- 包内主程序为 `svm-native-win32.exe`；
- GitHub Actions 对包体积、中文文本、禁止运行库文件做门禁检查。

## 模块原则

- 串口后端只负责传输和错误诊断；
- UI 负责组织流程，不承载协议算法；
- 分析逻辑放在核心模块，由 native controller 和测试复用；
- 原始 TX/RX 记录优先进入存储，日志窗口只是可见工作集；
- 中文文案集中管理，避免乱码和散落字符串。

## 串口和 codec 边界索引

- Neutral transport：`src/transport/serial_types.h`、`serial_session.h` 和 `serial_write_queue.*`，只定义生命周期、字节、typed result 和队列语义。
- Win32 owner：`src/win32/win32_serial_session.*`，唯一拥有串口设备 `HANDLE`、generation、worker 和串口参数。
- RTU adapter：`src/transport/serial_rtu_transport.*`，在字节层之上处理 RTU exchange；CRC、retry、stale-RX 和协议错误不下沉到 neutral contracts。
- Future scanner/matcher codec：位于协议输出之上，负责可变位布局、Gray/其他编码、signedness 和 scaling；transport v2 不实现该通用 codec。
- 自动边界门禁：`scripts/check-transport-boundaries.py`；`transport_boundary_self_tests` 验证规则本身，`transport_boundary_tests` 扫描仓库，阻止 Win32/UI、matcher/codec、存储和旧门面反向依赖 `src/transport`。

依赖方向为 `scanner/matcher codec -> RTU/protocol -> SerialByteStream`。详细所有权、已有固定 `Gray16` 候选和未实现范围见 [Win32原生架构.md](Win32原生架构.md)。

## 主要目录

```text
src/win32/           Win32 native UI 和串口后端
src/core/            无框架核心能力
src/transport/       串口窄契约、RTU adapter 和写队列
src/native_storage/  Win32 native 存储
scripts/             构建、打包、检查和 Wine UI 截图脚本
.github/workflows/   CI、Windows 出包和压力测试
```
