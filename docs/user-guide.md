# 用户指南

状态：当前 Win32 native 文档骨架。详细操作说明将在 Phase 5 Task 02 补全。

适用对象：使用 `svm-native-win32.exe` 的中文 Windows 用户、开发测试工程师和现场调试人员。

## 当前版本口径

- 当前主发布物是 Win32 native 便携包。
- 主程序是 `svm-native-win32.exe`。
- Qt 路线源码仅作为历史基线和测试参考，不是当前轻量发布包。

## 计划覆盖

- 安装、解压和首次启动。
- 串口刷新、连接、断开和参数配置。
- 通信日志查看、筛选、搜索、复制、导出。
- 单发、多发、文件发送和发送历史。
- Modbus 扫描、候选生成、规则验证和报告导出。
- UI 偏好、日志缓存、暂停跟随和常见问题。
