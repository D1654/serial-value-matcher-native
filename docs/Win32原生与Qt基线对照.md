# Win32 Native 与 Qt 基线对照

状态：历史/过渡参考。当前主发布路线请优先阅读 [用户指南.md](用户指南.md)、[Win32原生架构.md](Win32原生架构.md) 和 [发布产物.md](发布产物.md)。

当前面向用户的发布包是 Win32 native v1.0.2。Qt 版本仍保留在源码中，主要作为历史基线、测试参考和后续迁移参考。

## 发布决策

| 项目 | Win32 native | Qt 基线 |
|------|--------------|---------|
| 当前用户发布 | 是 | 否 |
| 解压即运行 | 是 | 是 |
| 不依赖 .NET | 是 | 是 |
| 不携带 Qt DLL | 是 | 否 |
| 体积 | 轻量 zip，具体以 package summary 为准 | 明显更大 |
| 串口基础调试 | 是 | 是 |
| Modbus 扫描 | 基础 FC03/FC04 | 是 |
| 候选分析/规则验证 | 轻量闭环 | 是 |
| UI 技术 | Win32 | Qt Widgets |

## Native 已覆盖

- 串口连接、参数、DTR/RTS、流控；
- 文本/HEX/十进制/二进制发送；
- 发送历史、定时发送、快捷发送、文件发送；
- 通信日志显示、筛选、搜索、复制、导出；
- 可配置日志缓存和暂停跟随；
- FC03/FC04 Modbus 扫描；
- 候选生成、规则验证、报告导出；
- GitHub Actions 出包和体积门禁。

## 仍需真机验证

- 高速串口和长时间运行；
- 不同 USB 转串口芯片的端口描述；
- DTR/RTS 和硬件流控；
- 大范围扫描时的取消、超时和恢复；
- 真实设备上的候选分析准确性。

## 后续判断标准

继续增强 Win32 native 时，应优先满足：

1. 中文可读性不下降；
2. 体积和依赖保持轻量；
3. 高负荷日志和串口操作稳定；
4. 业务流程比视觉微调更优先；
5. 每次发布都有 CI 包检查和必要真机验证记录。
