# Windows Native UI 验收清单

本文用于验证 `svm-native-win32.exe`。该目标是第一阶段 Win32 原生 UI shell，默认不替代 Qt baseline。

## 自动验证

在 Windows 构建目录运行：

```powershell
.\svm-native-win32.exe --self-test
```

期望：

- 进程退出码为 `0`；
- 不弹出窗口；
- 不加载 `Qt6*.dll`、`qsqlite.dll` 或 .NET/C# 运行库；
- 能创建临时 native storage，并写入 raw I/O、串口 Profile 和发送历史记录；
- 能完成中文 UTF-8/UTF-16 往返转换检查。

## 手工验证

| 场景 | 步骤 | 期望结果 |
|------|------|----------|
| 中文显示 | 启动程序 | 窗口标题、菜单、按钮、状态栏均显示正常中文，不出现乱码 |
| 启动 | 双击 `svm-native-win32.exe` | 显示中文窗口“串口值匹配器 Win32 Native”，窗口上方有“文件 / 串口 / 工具 / 分析 / 帮助”菜单 |
| 刷新串口 | 插入 USB 转串口并点击“刷新” | 下拉框出现 `COMx` |
| 串口参数 | 修改波特率、数据位、校验、停止位、流控、DTR/RTS | 点击“连接”时使用当前参数；参数无效时显示中文错误 |
| Profile | 选择串口参数并点击“保存配置” | 下次启动恢复默认配置 |
| 文本发送 | 选择“文本”，输入中文或 ASCII，选择行尾后点击“发送” | 日志显示 TX 字节，设备收到 UTF-8 字节流和所选行尾 |
| HEX 发送 | 选择“HEX”，输入 `01 03 00 00 00 01` | 非法字符或奇数半字节给出中文错误，合法输入发送成功 |
| 发送历史 | 成功发送后展开“发送历史” | 可选择最近发送内容并回填输入框 |
| 接收 | 外部设备或回环线返回数据 | 日志显示 RX HEX 字节 |
| 暂停滚动 | 点击“暂停滚动”后持续接收 | 状态栏显示隐藏日志数量；数据仍写入 native 存储 |
| 自动重连 | 勾选“自动重连”后拔插设备 | 设备恢复后按上次参数尝试重连，并显示中文状态 |
| Modbus 扫描 | 连接串口，设置从站/功能码/起止地址，点击“Modbus 扫描” | 执行 FC03/FC04 基础扫描，TX/RX 写入日志和 native 存储 |
| 分析入口 | 点击“分析工作区 / 规则验证 / 导出报告” | 不应无响应；已实现部分进入工作流，未完全恢复部分给出明确中文说明 |
| 长期运行 | 连续接收超过日志上限 | 日志自动清空并提示，窗口不持续涨内存 |
| 断开 | 点击“断开”或关闭窗口 | 串口句柄释放，其他串口工具可重新打开端口 |

## 当前边界

- 该 shell 覆盖核心串口调试工作流：刷新、连接、断开、完整串口参数、文本/HEX 发送、行尾、发送历史、Profile、接收日志、raw I/O 存储、暂停滚动和基础自动重连。
- 基础 FC03/FC04 Modbus 扫描入口已接入 Win32 串口后端和 native 存储，用于真机验证轻量路线。
- 候选分析、稳定性分析、规则编辑和报告导出仍未达到 Qt baseline 的完整交互深度；入口会显示明确中文说明，不允许静默缺失。
