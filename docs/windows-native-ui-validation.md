# Windows Native UI 验收清单

本文用于验证 `svm-native-win32.exe`。该目标是第一阶段 Win32 原生 UI shell，默认不替代 Qt baseline。

## 自动验证

在 Windows 构建目录运行：

```powershell
.\svm-native-win32.exe --self-test
```

期望：

- 进程退出码为 `0`；
- 不弹出窗口；
- 不加载 `Qt6*.dll`、`qsqlite.dll` 或 .NET/C# 运行库；
- 能创建临时 native storage，并写入一条 raw I/O 记录。

## 手工验证

| 场景 | 步骤 | 期望结果 |
|------|------|----------|
| 启动 | 双击 `svm-native-win32.exe` | 显示中文窗口“串口值匹配器 Win32 Native” |
| 刷新串口 | 插入 USB 转串口并点击“刷新” | 下拉框出现 `COMx` |
| 连接 | 选择端口和波特率，点击“连接” | 状态显示已连接，日志追加系统消息 |
| 文本发送 | 取消 HEX，输入中文或 ASCII，点击“发送” | 日志显示 TX 字节，设备收到 UTF-8 字节流 |
| HEX 发送 | 勾选 HEX，输入 `01 03 00 00 00 01` | 非法字符或奇数半字节给出中文错误，合法输入发送成功 |
| 接收 | 外部设备或回环线返回数据 | 日志显示 RX HEX 字节 |
| 长期运行 | 连续接收超过日志上限 | 日志自动清空并提示，窗口不持续涨内存 |
| 断开 | 点击“断开”或关闭窗口 | 串口句柄释放，其他串口工具可重新打开端口 |

## 当前边界

- 该 shell 覆盖核心串口调试工作流：刷新、连接、断开、文本/HEX 发送、接收日志、raw I/O 存储。
- 高级 Modbus 扫描、候选分析、规则验证面板暂不进入第一版 shell；相关 Qt-free 核心已准备，后续按体积和交互复杂度逐步接入。
