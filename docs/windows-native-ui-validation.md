# Windows Native UI 验收清单

本文用于验证 `svm-native-win32.exe`。该目标是第一阶段 Win32 原生 UI shell，默认不替代 Qt baseline。

## 自动验证

在 Windows 构建目录运行：

```powershell
.\svm-native-win32.exe --self-test
```

期望：

- 进程退出码为 `0`；
- 不弹出窗口；
- 不加载 `Qt6*.dll`、`qsqlite.dll` 或 .NET/C# 运行库；
- 能创建临时 native storage，并写入 raw I/O、串口 Profile、发送历史记录和界面偏好；
- 能完成中文 UTF-8/UTF-16 往返转换检查；
- 能通过 Win32 native 关键工具栏、支持范围布局、强制小尺寸布局和极小退化尺寸布局自检。

在 Debian/Wine 本地闭环 UI 时运行：

```bash
SVM_WINEPREFIX=/tmp/svm-native-wine64-ui2 \
SVM_XDG_RUNTIME_DIR=/tmp/xdg-runtime-root \
SVM_WINE_UI_OUTPUT_DIR=/tmp/svm-native-wine-ui \
scripts/capture-windows-native-ui-wine.sh
```

期望生成：

- `root.png`：默认启动窗口；
- `tab-single.png`、`tab-quick.png`、`tab-file.png`、`tab-scan.png`、`tab-settings.png`：默认尺寸标签页矩阵；
- `tab-single-fast.png`、`tab-quick-fast.png`、`tab-file-fast.png`、`tab-scan-fast.png`、`tab-settings-fast.png`：默认尺寸标签页切换后的快速帧，用于暴露明显白屏；
- `compact-tab-single.png`、`compact-tab-quick.png`、`compact-tab-file.png`、`compact-tab-scan.png`、`compact-tab-settings.png`：`760x520` 紧凑尺寸标签页矩阵；
- `compact-tab-single-fast.png`、`compact-tab-quick-fast.png`、`compact-tab-file-fast.png`、`compact-tab-scan-fast.png`、`compact-tab-settings-fast.png`：紧凑尺寸标签页切换后的快速帧；
- `tab-clicks.txt`：默认尺寸和紧凑尺寸的标签页点击坐标，用于确认自动化实际点在 Tab 标题行；
- `self-test.log` 内容为 `ok`。

脚本会对标签页截图执行基础非空/非全白检查；Change #22 后默认尺寸继续使用鼠标点击标签页，`760x520` 紧凑尺寸使用单独校准的屏幕坐标点击，避免控件密度变化后仍按旧坐标误点。若出现整窗白屏、窗口未捕获、标签页切换失败或 `tab-clicks.txt` 坐标明显脱离 Tab 标题行，应直接视为 UI 闭环失败。

## 当前边界

- 该 shell 覆盖核心串口调试工作流：刷新、连接/断开单按钮、完整串口参数、文本/HEX/十进制/二进制字节流发送、发送编码、行尾、发送历史、定时发送、10 槽快捷发送、文件分块发送、Profile、界面偏好持久化、彩色通信日志、日志显示格式、日志编码、日志时间开关、日志缓存、日志过滤/搜索/复制/导出、raw I/O 存储、分段状态栏、暂停滚动、跟随最新日志和基础自动重连。
- 通信日志 UI 已采用有界工作集；高负荷长期运行时优先保证 UI 内存可控。Change #23 后可见日志缓存最高可配置到 100M，但 1000M 级日志应通过后续虚拟/分页或磁盘背书日志视图实现，不能直接把 RichEdit 可见文本框推到 1000M。
- 基础 FC03/FC04 Modbus 扫描入口已接入 Win32 串口后端和 native 存储，并改为可停止的后台执行路径；Change #23 后扫描期间会按块数显示进度条和状态栏进度，用于真机验证轻量路线。
- 候选生成、规则验证和报告导出已具备轻量 native 工作流；稳定性分析、规则编辑表格和更丰富的证据浏览仍未达到 Qt baseline 的完整交互深度。
- Change #19 后底部工作区采用稳定高度和标签页矩阵验收：默认尺寸与 `760x520` 紧凑尺寸下，“单发 / 多发 / 文件 / 扫描 / 设置”的核心控件均应可见，切换标签后不得出现其他页面控件残影。
- Change #20 后标签页切换改为局部无擦除刷新，Wine UI 验证增加快速帧和非全白检查；Modbus 扫描期间的断开请求会在扫描取消完成后真正关闭串口，DTR/RTS 与串口参数入口在扫描运行时冻结。
- Change #21 后“模式 / 编码 / 行尾 / 发送历史”明确归属“单发”页，其他标签页不得出现这排控件，也不保留它们的布局占位。
- Change #23 后标签页切换路径去掉重复整页 show/hide 和同步整块刷新，Wine 默认尺寸与 `760x520` 紧凑尺寸截图覆盖扫描页进度条和快速帧非空白。
